# Project Instructions

Project ini adalah aplikasi Laravel Sistem Informasi Desa.

Aturan umum:
- Gunakan Bahasa Indonesia.
- Jangan ubah file di luar scope tugas.
- Prioritaskan bug Critical dan High.
- Setelah mengubah kode, jelaskan file yang berubah.
- Setelah fix, sertakan hasil retest.
- Jangan hapus fitur existing tanpa alasan jelas.

Agent khusus:
- agents/laravel-qa-master.md untuk testing CRUD, bug fixing, validasi, route, controller, model, blade.
- agents/sid-design-master.md untuk review UI/UX, desain halaman, layout, warna, tabel, form, dan flow user.
